# Disboard Web v1

<a class="vp-external-link-icon" href="https://disboard.team" target="_blank" rel="noopener noreferrer">Ir a sitio web</a>

Nueva versión del directorio de servidores de Discord de Disboard, enfocada en la búsqueda y el descubrimiento de comunidades.

La aplicación evoluciona la experiencia web con **React**, navegación cliente y una estructura preparada para mejorar el descubrimiento de servidores.
